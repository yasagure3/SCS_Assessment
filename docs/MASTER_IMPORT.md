# 評価項目マスタと自己評価Excelの取込

管理者が診断メニューの「自己評価Excel取込」から `.xlsx` を選択し、差分を確認して取り込む。マスタの文言が変わっていても取り込める。既存の「Excel取込」は、2026年3月27日版の固定マスタに一致する回答のみを取り込む従来機能として維持している。

## 操作の流れ

1. 顧客・案件を開き、診断を選ぶ。新規案件の場合は通常どおり案件を作成する。
2. 管理者用「自己評価Excel取込」でファイルを選ぶ。変更元は現在開いている診断のマスタ版になる。
3. 追加・変更・削除候補、自己評価件数、O〜Rの原文を確認する。
4. 確認チェックを入れ「マスタと自己評価を取り込む」を押す。
5. 同じ案件に作成された新しい診断のダッシュボードを開く。
6. 評価基準一覧で理由・根拠・補足を整え、証跡を紐付ける。
7. 「公式シート回答・Excel出力」で診断の内容を参照し、公式の質問ごとに清書して保存・出力する。

既存診断のマスタ、回答、証跡、履歴、固定済み報告版は変更しない。新しい診断には対象範囲を引き継ぐ。既存の証跡・助言・公式回答は自動転記しない。

## 入力形式

現行SCS ★3の81評価基準を対象とする。★4は参考マスタとして保持し、回答・集計には含めない。81件以外はプレビューで件数を示して確定を停止する。

| 列 | 意味 | 保存先 |
|---|---|---|
| B〜E | 大分類・中分類の番号と名称 | マスタ出典、C列は一覧の分類 |
| F〜J | 要求事項番号、★3/★4の対象表示、要求事項名・本文 | マスタ出典、F・J列は評価項目マスタ |
| K | ★3/★4 | 対象レベルの判別 |
| L | 評価基準No. | 評価項目のID |
| M | 評価基準本文 | 評価項目マスタ・回答画面 |
| N | NIST CSF機能 | マスタ出典 |
| O | 自己評価 | 原文と現在の自己評価 |
| P | 理由 | 原文と判定理由・確認メモ |
| Q | 根拠および実施する事／根拠 | 原文と確認した既存の根拠 |
| R | 補足情報／補足 | 原文と補足情報 |

先頭20行から見出しを検出し、対応シートが複数ある場合は停止する。今回のように見出しが4行目で、上部に集計式がある形式にも対応する。明細の数式・不正な型、重複ID、不正な自己評価、過大ファイルは取り込まない。元ファイルを変更せず、読み込みはWeb Workerで実行する。

○は満たしている、△は判断微妙、✖・×・✕は不足、空欄と `-` は未回答。原文の記号・改行・空白を保持する。Q列を今後の作業へ自動分解せず、担当者が整理する。

## 保存と差分

- 新しい `standards` と81件の `criteria` を封印し、変更不能な版として登録する。
- `master_import_sources` にB〜N列の全行、出典シート・見出し行・ファイル名・取込者・日時を保存する。O〜R列は顧客の診断ドキュメントにのみ保存する。
- 元の診断の回答を更新せず、同じ案件に新規診断を作成する。
- マスタ、診断、操作記録、監査ログはD1の1バッチで保存する。途中失敗はロールバックする。
- プレビューのハッシュと診断リビジョンを再検証する。操作番号による再送は同じ結果を返す。
- APIでも管理者権限を確認し、書込時に有効な管理者・未保管の案件であることを再確認する。
- 差分は要求事項番号・分類・要求事項本文・評価基準本文・表示順を比較する。WindowsのCRLFとLFは比較時のみ同一視する。削除候補は新しい版からの除外を意味し、既存版からの物理削除は行わない。

## 公式出力テンプレートとの分離

公式出力は従来の `public/official/` 配下の固定テンプレートと `official-scs-v1.1.json` のセル対応を使う。取込Excelでこのテンプレートを置換しない。公式回答は別データとして保存し、取込O〜Rを自動的に適合判定へ変換しない。公式画面で編集済みの理由・根拠・補足を参照できる。

取込マスタのID集合と公式テンプレートが一致しない場合は、公式回答の保存・出力画面への進行を止め、対応関係の確認を求める。

## 検証

- `src/front/workers/parseMasterWorkbook.test.ts`: 見出し移動、集計式、原文保持、重複・数式・形式エラー。
- `src/front/pages/MasterImportPage.test.tsx`: 確認操作、プレビュー連携、不正Excel、保管状態、検査中断。
- `test/worker/master-imports.test.ts`: 原文保持、旧診断保護、再送、権限、改ざん、件数不足、ロールバック、公式回答分離。
- `tests/e2e/master-import.spec.ts`: 画面からファイル選択・差分確認・取込、81マスタと324セル照合、保存・再ログイン後の再表示、元回答の保護、狭幅画面。

実ファイル検証は `SCS_MASTER_XLSX` にローカル絶対パスを指定できる。指定しない場合は匿名の合成Excelで実行する。結果と画像はGit管理外の `.local/master-import-actual/`（実ファイル）または `.local/master-import-regression/`（合成データ）に保存する。`SCS_E2E_STATE_DIR` で検証DBを分離できる。認証fixtureはローカル専用で、本番ビルドへは含まれない。
