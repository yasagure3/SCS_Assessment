## 差分と回答方法

旧版と新版の評価基準本文を全件比較した。IDの増減はなく、★3は26要求事項・81評価基準を維持する。本文の変更は★3の `4-4-4-1`、`4-4-4-2`、★4の `4-4-2-1`。

- `4-4-4-1`：情報機器・OS・ソフトウェアの対象表記、サポート終了品をやむを得ず使用する場合のリスク低減策を明記。10月29日には「軽減」から「低減」の誤字修正。
- `4-4-4-2`：アップデートの期限に対応できない場合の具体策は自己評価等ガイド・解説書に説明する構成へ変更。ガイドのリスクに応じた対応計画・代替策の条件を参照する。
- `4-4-2-1`（★4）：サポート終了品への対応の記述を関連基準と整合。

自己評価等ガイド第3章に基づき、適合基準ごとに「適合」「不適合」、質問ごとの文書名・実施内容等を回答する。対象外の場合はガイド別紙の条件を利用者が確認して理由を記載する。アプリは理由の入力を必須にするが、適用対象外の妥当性や制度取得を自動判定しない。未回答は空欄のまま出力する。従来の「△」を不適合・適合へ自動変換しない。

実ファイルから★3の108適合基準行、89質問、適用範囲11質問を抽出。`1-2-1-1` など1つの評価基準が複数行に対応するため、回答キーを「評価基準ID:適合基準の連番」とした。質問がない行に回答を書き込むAPI入力は拒否する。

2つの公式Excel間にも小さな表記差がある。`3-1-3-1` と `4-4-4-1` の箇条書き記号、`4-4-1-2` の「外部記録媒体」（要求事項Excel）と「外部記憶媒体」（テンプレート）。画面の評価基準本文はSCS-400、適合基準・質問はSCS-410APを採用し、出力原本の本文を改変しない。差分全文を生成マスターの `templateDifferences` に記録した。

### 出力対応の例

「【★3用】アセスメントシート」の I列のIDを実ファイルで解決して対応を生成した。参照数式でIDを引き継ぐ行も追跡する。全対応はJSONの `rows` に明示。

| 入力 | 出力先 |
|---|---|
| 登録組織名・住所・取得単位・適用範囲 | P2・P3・P4・P5 |
| 評価基準版・ガイド版 | P13=`1.1`、P14=`1.0` |
| `1-2-1-1:1` の判定・質問回答 | P19・R19 |
| `1-2-1-1:2` の判定（質問なし） | P20（R20には書かない） |
| `7-1-1-1:2` の判定・質問回答 | P126・R126 |
| 対象外・理由 | 該当評価基準の全行のL列・M列。対象外のP列は空欄 |
| 適用範囲11質問 | 「【★3・★4共通】適用範囲に関する質問事項」のD3:D13 |

テンプレートのハッシュが違えば出力を拒否する。原本ZIP内の2つのワークシートXMLについて、対応表で確認した入力セルだけを文字列セルとして更新する。入力文字列は数式として解釈させない。数式、書式、入力規則、印刷設定、コメント、その他のXML、★4シートは保持する。確認責任者の記名や自己適合宣言を自動入力しない。

未保存の入力がある間は出力できない。出力時にAPIから保存済みの診断を再取得し、リビジョンを確認する。生成後にもアクセスを再確認し、画面移動・ログアウト・別ログイン後のダウンロードを抑止する。ファイル名には診断IDとリビジョンが入る。

## 既存データへの影響

- 旧 `scs-20260327-star3` マスターは変更しない。新版 `scs-20261028-v1.1-star3` を追加する。既存診断のstandardIdや履歴・固定報告版を書き換えるmigrationはない。
- 既存の診断JSONに省略可能な `officialAnswers` を追加。旧回答のO〜R原値、○△×、理由、根拠、今後の作業、補足を保持する。
- 旧診断からも最新版の公式回答を別に保存できる。その場合、旧版回答を自動移行しない旨を画面に表示する。
- 公式回答の変更は関連する助言の根拠ハッシュに含め、確定助言の再確認を促す。同じ版での再診断は回答コピー指定時に公式回答も引き継ぐ。
- 公式回答の集計・出力と、従来の診断メモの集計・PDF/作業用Excelは区別する。既存の固定報告版には後から公式回答を挿入しない。
- 導入時には検証済みのmainを使用し、既存DBのバックアップ・migration適用・検証環境への公開・公開画面での保存とExcel出力の確認を行う。
